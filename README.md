# Ryan Watts — Portfolio & Blog

Personal portfolio website for Ryan Watts, Principal AI & Data Engineer.

Built with **Next.js 16**, **Tailwind CSS 4**, and deployed to **Vercel**.

## Features

- Ghost blog-inspired minimal dark theme
- LinkedIn-style resume/profile flow
- Career timeline
- Technical blog with AI & data engineering writing
- Fully static — blazing fast on Vercel Edge

## Stack

- **Framework**: Next.js 16 (App Router, fully static)
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Deployment**: Vercel

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Deploy

Automatically deployed to Vercel on push to `main`.
