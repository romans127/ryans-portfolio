# Ryan Watts — Portfolio

Personal site for Ryan Watts, Director of Data at Vitable Health and former Head of AI at DVx.

Built with **Next.js 16**, **Tailwind CSS 4**, and deployed to **Vercel**.

## What’s here

- Control-plane visual language (warm ink, copper, signal mint, Instrument Serif)
- Interactive warehouse → agent → MCP schematic
- Career timeline aligned to the standing Data & AI resume
- Projects, including the Go MCP OpenAPI proxy
- Technical writing

## Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS 4
- **Icons**: Lucide React
- **Content**: `src/lib/site.ts`
- **Deployment**: Vercel

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```
